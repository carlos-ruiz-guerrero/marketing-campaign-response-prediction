# Bank Marketing Campaign Response Prediction

## Project Overview

This project analyzes a bank marketing campaign dataset from the UCI Machine Learning Repository to identify the factors that influence customer subscription to term deposit products.

The analysis focuses on:

- Customer demographics
- Marketing campaign performance
- Customer segmentation
- Conversion drivers
- Predictive modeling

## Current Progress

- Data acquisition and validation completed
- Exploratory Data Analysis (EDA) completed
- Business\-oriented conversion analysis in progress

## Dataset

Source: UCI Machine Learning Repository \- Bank Marketing Dataset

Target Variable:

- subscribed (Yes/No)
